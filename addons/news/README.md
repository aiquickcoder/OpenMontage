# Новости «ЧП · Москва» — вертикальный ролик ~30 с с котом-ведущим

Формат утверждён владельцем 2026-10-24. Эталоны (оба одобрены: «получилось прямо отлично»):
- `story.example.json` — пожар в «Узком»: видео с места из поста.
- `projects/news-novatorskaya-shpric/story.json` (сервер) — укол шприцем на «Новаторской»: БЕЗ видео с места —
  2 фото станции с Wikimedia + реалистичные Flow-иллюстрации, звук метро, джингл. Это образец для событий без медиа.

```
0 – ~6 с    КОТ-ВЕДУЩИЙ в студии говорит подводку     нижняя плашка: [ЧП · МОСКВА] + заголовок
~6 – ~28 с  B-ROLL, смена плана каждые 3 с            закадр того же голоса, верхняя плашка, титры
~28 – 31 с  КОТ: «Подписывайтесь…»                    затемнение в конце
```

Всё бесплатно, кроме голоса: OpenRouter `openai/gpt-audio` стоит около 4 центов за ролик.
Картинки рисует Flow (Nano Banana) на бесплатном аккаунте. Сборка идёт в HyperFrames. **Veo и Omni не тратим.**

### Источник новостей
Это веб-превью Telegram-каналов `t.me/s/<канал>`. В одном посте там есть и текст, и прямые ссылки на фото и видео.
- `moscowach`, `moscowmap` — московские каналы, берутся целиком.
- `shot_shot`, `mash`, `bazabazon`, `ostorozhno_novosti` — федеральные, с гео-фильтром по Москве.

Фильтр:
- регулярка ЧП (пожар, ДТП, нож, шприц…) и гео-регулярка (москв, метро, МКАД…);
- отсев рекламы;
- дедупликация по первым 7 словам. Одно событие из нескольких каналов склеивается, остаётся самый полный текст, медиа объединяются.

Медиа качаются **сразу**: токены в ссылках `telesco.pe` живут недолго. HTML каналов считается недоверенными данными: из него только достаём текст регуляркой и ничего не исполняем.

### Этап 1: поиск новостей (`pick.py`)
`pick.py` сам запускает харвестер (`--no-harvest` — взять текущую базу) и пишет `<база>/candidates.json`:
`candidates` (подходящие, по убыванию `score`) и `skipped` (с причиной). Для каждого: текст без реакций и хвостов
каналов, возраст в часах, реакции, медиа, каналы, ссылки, локальные файлы медиа.
- **Отсев** (`SKIP`): война/БПЛА/политика, суицид, сексуальное насилие, дети-жертвы; «не Москва»; старше `--hours` (36);
  «уже сделано» — ссылки или `source.key` совпадают с `projects/news-*/story.json`.
- **Балл**: 1,5·log10(реакции) + медиа (видео 3, фото 1,5) + 1 за каждый доп. канал + 0,8 за каждое «сильное» слово ЧП
  (до 3) − возраст/12 − 2, если это не ЧП (курьёз).
- **Продолжение уже сделанной истории** (например, «пострадали пожарные в „Узком“») — новый ролик можно, если в нём
  новый факт; в подводке так и сказать: «Продолжение истории…».
- В `story.json` записывать `source.key` (ключ события из базы), чтобы `pick.py` его больше не предлагал.

### Какое событие брать
1. Московское, свежее (не старше 24 ч) и понятное без контекста.
2. С видео с места лучше всего. С фото тоже хорошо. Без медиа можно, тогда планы — иллюстрации и фото места (см. ниже).
3. Не берём:
   - войну, атаки БПЛА и политику (пример: «атака ВСУ на автобус» — пропустить);
   - суициды, детей-жертв, изнасилования;
   - «весёлые» новости, которые не ЧП (кривые дома под Москвой и т. п.).

## story.json

```jsonc
{
 "slug": "news-<коротко>",
 "title": "…", "tag": "ЧП · МОСКВА", "date": "24 октября",
 "headline": "Горит санаторий «Узкое» — тушат вертолётами",   // ≤ 60 знаков, 2 строки
 "source": {"channels": [...], "links": [...], "dt": "..."},
 "anchor": {"dir": "addons/news/anchor_cat",
            "intro": "Здравствуйте, это «ЧП Москва». <суть одной фразой>.",
            "outro": "Подписывайтесь, чтобы первыми знать, что происходит в городе."},
 "narration": {"engine": "openrouter", "voice": "cedar", "model": "openai/gpt-audio",
               "text": "<сюжет, 45–55 слов>"},
 "illustration_style": "...", "illustrations": [{"id": "i1", "prompt": "..."}],   // только если нужны иллюстрации
 "shots": [
   {"src": "media/fire.mp4", "in": 0.3, "credit": "Видео: 112 / @moscowach"},
   {"src": "media/station.jpg", "credit": "Фото: Автор / Wikimedia, CC BY 4.0"},
   {"src": "illustrations/i2.png", "label": "ИИ-иллюстрация", "sfx": {"src": "metro_train_doors_ru.mp3", "volume": 0.45, "offset": 20}}
 ],
 "music": {"src": "tension_suspense_building_delosound.mp3", "volume": 0.22},
 "sound": {"ambience": {"src": "metro_moscow_station.mp3", "volume": 0.22, "offset": 5},
           "whoosh": {"src": "whoosh_transition.mp3", "volume": 0.3}}
}
```

### Текст: правила
- **Сколько слов.** Подводка + сюжет + финал ≈ 75–85 слов, это ≈ 30–33 с у голоса `cedar`. Подводка — 10–14 слов, финал фиксированный.
- **Только факты из поста.** Ничего не додумываем: ни времени суток, ни района, ни деталей («обернувшись» — нельзя, если в посте этого нет). Если каналы расходятся, берём то, что совпадает, или самый подробный пост.
- **Числа словами**: «восемьсот квадратных метров», «восемнадцатилетняя». Так их точно прочтёт голос, и так же они выйдут в титрах.
- **Нейтральный тон.** Без «жесть», «шок», эмодзи и оценок. Последняя фраза сюжета — итог: «пострадавших нет», «возбуждено дело», «заявление в полицию».
- **Можно добавить одну практичную фразу-совет**, если она прямо следует из события («если почувствовали укол — сразу к сотрудникам метро и к врачу»).
- **Имена.** Имена пострадавших и подозреваемых не называем, даже если они есть в посте: «30-летняя москвичка».

### Планы (`shots`): правила
- **Ритм.** Один план = 3 с (`SHOT_S`). `build.py --voice-only` печатает, сколько планов нужно (обычно 7–8). Последний план растягивается до финала ведущего.
- **Видео из поста.** Без `in` каждый следующий план с того же файла продолжает с места, где закончился предыдущий. С `in` — с заданной секунды: так выбираются самые сильные моменты, но первым ставим самый сильный. Если файл короче, план стартует с начала.
- **Подпись** `credit` для каждого чужого кадра: «Видео: <вотермарк> / @<канал>» или «Фото: <автор> / Wikimedia, <лицензия>».
- **Иллюстрации — РЕАЛИСТИЧНЫЕ** (решение владельца 2026-10-24: мультяшный b-roll ломает новостной формат; мультяшный только кот).
  - `illustration_style` = «Realistic documentary photograph … natural light, slight grain, not a render, not a cartoon» +
    точное описание реального места (эталон: `projects/news-novatorskaya-shpric/story.json`).
  - Ярлык `"label": "ИИ-иллюстрация"` обязателен, но он почти невидим: 20 px, белый 42 %, без плашки, в нижнем правом
    углу кадра (владелец не хочет заметный ярлык; совсем без пометки реалистичный ИИ-кадр реального ЧП = фейк).
  - Контекст, а не реконструкция: место, толпа, двери, полиция, камеры. Сам момент — только деталью (рука со шприцем).
    Лиц пострадавших/подозреваемых нет (спиной, вне кадра, не в фокусе). Никакой крови и травм.
  - Текст в кадре не пишем (в промпт добавляется «No text…»). Промпты без «panel», «film», «cinematic».
  - Nano Banana Pro к вечеру часто отвечает пусто (квота) — `gen_shots.py` сам уходит на Nano Banana 2, качество то же.
- **Wikimedia Commons** — для реального места (станция, улица, здание). Берём только CC BY / CC BY-SA / CC0, `CREDITS.txt` кладём рядом. Перед использованием фото открываем и смотрим.
- **Порядок планов.** Сначала самое сильное, дальше хронология события, в конце итог (полиция, тушение, место).

## Как устроена сборка (`build.py`)
1. **Голос.** Подводка, сюжет и финал озвучиваются одним дублем, поэтому голос и интонация везде одни.
   - `engine: openrouter` → `openrouter_voice.py`. Это чат-модель `openai/gpt-audio`: системный промпт «прочитай слово в слово, серьёзный диктор», стрим PCM16 24 кГц.
   - Транскрипт сверяется со сценарием. При совпадении < 97% дубль перезаписывается, до 3 попыток.
   - Дальше нормализация громкости (`loudnorm -16 LUFS`) → `assets/narration.mp3`.
   - Другие движки: `piper` (локальный, бесплатный, синтетичный, модели в `~/.piper/models`) и `fish` (Fish Audio, нужен ключ).
2. **Тайминги.** faster-whisper (`tools/analysis/transcriber.py`, small, ru) даёт времена слов. Слова **сценария** привязываются к услышанным через difflib: в титрах наш текст, а не ошибки распознавания. Голос стартует на 0,3 с (`VOICE_AT`), все времена в `assets/timing.json` даны в секундах композиции. Окно b-roll — от конца последнего слова подводки до начала первого слова финала.
3. **B-roll.** ffmpeg собирает один немой клип 1080×1920 (`assets/broll.mp4`):
   - фон — размытая и затемнённая копия кадра;
   - картинка — горизонтальная обрезается в рамку 1080×760…1000 по центру (y=930), вертикальная (h/w > 1,4) идёт на весь экран;
   - у стоп-кадров медленный наезд на 7% (zoompan с трёхкратным запасом против дрожания);
   - у кадров с `label` (картинки Flow) сначала закрашивается «звёздочка» Flow в правом нижнем углу (`remove_sparkle`).
4. **Кот** (`anchor.py`, ассеты в `anchor_cat/`). Базовый кадр плюс три правки Flow того же кадра: `open` (рот открыт), `mid` (приоткрыт), `blink` (глаза закрыты).
   - `prepare`: ECC-выравнивание правки по базе. В патч идут только изменившиеся пиксели внутри `mouth_box` / `eyes_box` (координаты кадра 1080×1920, `anchor.json`), с растушёвкой. Голова не двигается никогда. Результат — `anchor_cat/layers/`.
   - Рот: громкость голоса по кадрам → `closed` / `mid` / `open`, каждое состояние держится минимум 2 кадра («на двойках»).
   - Моргание каждые 3,1–4,3 с. Пока кот говорит, камера наезжает на 4,5%.
   - Новый ведущий = новая папка с `base.png`, `open.png`, `mid.png`, `blink.png`, `anchor.json` и затем `python addons/news/anchor.py prepare <папка>`. Правки рисуются промптом «Reproduce the attached image exactly… Change ONLY this: …», в рефе `base.png`. Для `open` брать вариант, где глаза не поменялись.
5. **HyperFrames** (`hyperframes/index.html`):
   - `<video id="broll">` в окне b-roll, слой кота под ним;
   - нижняя плашка на подводке, верхняя плашка `#plate` (тег, дата, заголовок) на b-roll;
   - незаметный ярлык `ИИ-иллюстрация` и подписи источника;
   - титры по 2–4 слова из реальных таймингов, на тёмной подложке, y=1500;
   - голос, музыка на 0,12 (≈ −18 дБ) с уходом за 1,5 с, затемнение 0,6 с.
   - Рендер: `hyperframes check` → `render --strict`, 30 fps. На сервере `HYPERFRAMES_BIN=/opt/node22/hyperframes.sh`.
6. **QA.** `qa/contact.jpg` — по кадру из середины каждого плана, `qa/report.json` — длительность и разрешение. Смотреть глазами: кадры ведущего (рот, плашка), каждый план (подпись, ярлык), титры не перекрывают важное.

Флаги: `--voice-only` (голос + сколько нужно планов), `--retime` (не заказывать голос заново: тот же `assets/narration.mp3`), `--no-render`.

## Звук (`sound_bed`, одна дорожка `assets/sfx.wav`)
Звуки — Pixabay (Content License, без Content ID), лежат в `/opt/openmontage/sfx` (+ `LICENSES.md`), на Mac — `~/Downloads/sfx_chp`.
Pixabay отдаёт страницы только настоящему браузеру: новые звуки ищем через Chrome-расширение Claude (ссылку `cdn.pixabay.com/download/audio/…` берём со страницы), качаем curl'ом **с Mac** (с сервера CDN недоступен) и копируем на сервер.
- `sound.sting` — новостной джингл под приветствием. **По умолчанию НЕ ставим**: владелец принял его за «не ту музыку».
- `sound.ambience` — атмосфера места под всем b-roll, зацикливается, плавный вход/выход (метро: `metro_moscow_station.mp3`; пожар: `fire_crackling.mp3`; улица: сирены).
- `sound.whoosh` — на переходах кот → сюжет → кот.
- `shots[i].sfx` — разовый звук на плане (двери вагона, паника, далёкая сирена), `offset` = откуда в файле.
- Видео из поста со звуком — живой звук под голосом на 0,35 (`"audio": 0` — выключить).
Есть: metro_moscow_station, metro_train_doors_ru, metro_platform_muffled, news_intro_logo, news_jingle_radio, crowd_panic,
siren_police, siren_ambulance_distant, siren_passing, fire_crackling(_2), whoosh_simple, whoosh_transition.

**Готовые наборы по типу события** (проверены на эталонах; подложка выходит в среднем на ~16 дБ тише голоса):

| Событие | `sound` | разовые `sfx` на планах | Эталон |
|---|---|---|---|
| Пожар, есть видео | ambience `fire_crackling` 0,08 (offset 3) · whoosh 0,3 | не нужны: живой звук видео 0,35 | «Узкое» (`story.example.json`) |
| Метро, без видео | ambience `metro_moscow_station` 0,14 (offset 5) · whoosh 0,3 | двери `metro_train_doors_ru` 0,45 (offset 20), паника `crowd_panic` 0,18, полиция `siren_ambulance_distant` 0,2 | «Новаторская» |
| ДТП / улица | ambience `siren_passing` 0,15 · whoosh 0,3 | `siren_police` 0,3 на плане с полицией | — |
| Нож, драка, задержание | ambience `metro_platform_muffled` или без · whoosh 0,3 | `siren_police` 0,3 | — |

Перед тем как оставить живой звук видео из поста, проверить, нет ли в нём чужой речи (репортёр, крики с матом):
`Transcriber` на клипе → если слова есть, ставить плану `"audio": 0` или 0,15.

## Музыка
Одна на формат: `tension_suspense_building_delosound.mp3` (Pixabay, без Content ID), **громкость 0,22** — её должно быть слышно под голосом (на 0,12 её забивала подложка). `/opt/openmontage/music/` на сервере, `~/Desktop/pixabay_примеры/` на Mac.

## Автопилот (фабрика, сервер)
Каждый шаг — из `/opt/openmontage`, `.venv/bin/python`. Ключи (`OPENROUTER_API_KEY`, Telegram, Flow) лежат в `/opt/openmontage/.env`. Не печатать их.
**OpenRouter (модели OpenAI) не пускает российский IP сервера (403)** — `build.py` запускать с `https_proxy=http://127.0.0.1:10809` (локальный выход фабрики).
Сборка на сервере: `systemd-run --uid=factory -p EnvironmentFile=/opt/openmontage/.env -E HYPERFRAMES_BIN=/opt/node22/hyperframes.sh -E PATH=/opt/node22/bin:/usr/bin:/bin -E https_proxy=http://127.0.0.1:10809 … addons/news/build.py projects/<id>`.
1. `https_proxy=http://127.0.0.1:10809 python3 -I addons/news/pick.py --base /srv/factory/news_base` (поиск + отбор +
   ранжирование; t.me с сервера доступен только через прокси). «Уже сделано» считается по `projects/news-*/story.json`
   на ЭТОЙ машине — ролик, собранный на Mac, переносить на сервер хотя бы своим `story.json`.
2. Взять кандидата №1 из `candidates.json`; другого — только с причиной (в `qa/notes.md`). Пусто → `AUTOPILOT_RESULT: FAILED projects/<id> no-news`.
3. Написать `projects/news-<slug>/story.json`, скопировать медиа, при необходимости фото с Wikimedia.
4. Нужны иллюстрации → `nohup .venv/bin/python addons/news/gen_shots.py … > projects/<id>/illustrations.log 2>&1 &`, ждать `DONE`. Код 3 → `AUTOPILOT_RESULT: BUDGET projects/<id>`. Открыть **каждую** картинку; брак — удалить и перерисовать один раз.
5. `addons/news/build.py projects/<id>`. Открыть `qa/contact.jpg` и 2 кадра ведущего.
6. `addons/mural/publish.py projects/<id> --caption "<заголовок>" --tags "#москва #чп #новости ..."`.
7. Отправить в Telegram на одобрение: `addons/mural/send_telegram.py` через `systemd-run --wait` с `EnvironmentFile`.
8. Последняя строка: `AUTOPILOT_RESULT: READY projects/<id>`.

## Нельзя
- Убирать незаметный ярлык `ИИ-иллюстрация` с реалистичных ИИ-кадров.
- Писать факты, которых нет в источнике. Называть имена пострадавших и подозреваемых.
- Тратить Flow-кредиты на видео (Veo / Omni).
- Править скиллы конвейеров, схемы и `pipeline_defs`. Меняем только `projects/<slug>/` и `addons/news/`.
